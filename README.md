# EduFinance Hub – About and Calendar Pages

## Project Overview

This repository contains the **About** and **Calendar** components of the EduFinance Hub Term 3 project.

EduFinance Hub is a student-focused web application designed to support students with funding opportunities, financial planning, important academic dates and related activities.

My individual contribution focuses on the **Calendar** and **About** pages. The Calendar allows users to create, view, update, delete, search, filter and sort events. The About page provides information about the purpose, objectives and values of EduFinance Hub.

## Running the project in NetBeans
1. Clone or download this repository.
2. Open **Apache NetBeans IDE**.
3. Select **File > Open Project** and choose the project folder.
4. Allow Maven to download the required dependencies.
5. Run `TestDatabase.java` if you want to verify the database connection first.
6. Right-click the project and select **Run**.
7. Open the following pages in a browser:
   - Calendar: `http://localhost:8080/calendar`
   - About: `http://localhost:8080/about`

## Database and application flow
The user interacts with the Calendar interface served by `Main.java`. Calendar requests are passed to `CalendarDAO`, which uses `DBConnection` to communicate with the H2 database through JDBC. Database results are represented by `CalendarEvent` objects and returned to the interface for display. Create, update and delete operations are written to the database and reflected by the application.

## Error handling and validation
The project includes validation and feedback for calendar operations. Database connection failures are reported rather than silently ignored, and destructive actions such as deletion require confirmation.
